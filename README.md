# HOLDING 79 Transfer

Небольшой локальный сервис для месячного переноса конечных остатков внутригрупповых расчетов `79.2`/`79.3` на `79.1` и формирования симметричных операций в управляющей компании `ГК`.

Источник первой версии: ОСВ по счетам 79.2/79.3.
Выход: контрольный журнал + файлы операции МСФО в стандартном 27-колоночном формате `Загрузка_A_AA`.

## Утвержденная логика

- Дт остаток: source org `Дт 79.1 / Кт 79.x`; ГК `Дт 79.1(source org) / Кт 79.1(original supplier)`.
- Кт остаток: полностью зеркально.
- Одинаково для 79.2 и 79.3.
- `ГК` и `Б_ГК Финансовый отдел` являются конфигурацией/reference.

См. `docs/PRODUCT_CONTRACT.md` и четыре fixtures в `tests/golden/`.
